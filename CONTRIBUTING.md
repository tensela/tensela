# Contributing to Tensela

Thank you for wanting to help. Tensela is made for architects, so the most useful contributions are often not code:
a clearer sentence in the manual, a translation, an example, a report of something that confused you.

## Ways to help

- **Report a problem:** in [Issues](https://github.com/tensela/tensela/issues): what you did, what you expected,
  what happened, and the project file if you can share it. A security problem goes by email instead: see
  `SECURITY.md`.
- **Fix or translate the manual:** it lives in `manual/` (`en/` for English, `es/` for Spanish), as Markdown files.
- **Share an example:** a `.tela` file that shows a technique well, in `examples/`.
- **Code:** for anything bigger than a small fix, open an issue first so we can agree on the approach.
