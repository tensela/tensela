# The Tensela name and logo

The code of Tensela is free software under the GNU General Public License, version 3 or later. That licence covers
the code. It does **not** cover the **name “Tensela”** or the **Tensela logo**, which belong to Victor Crespo.

This page says what you can do with them, so that people always know which program is the real Tensela.

## You can, without asking

- Say that you use Tensela, write about it, teach it, make tutorials and videos about it.
- Say that your work was made with Tensela, and use the name and logo to link to tensela.com.
- Share unchanged copies of Tensela, with its name and logo, for free.
- Call a project “compatible with Tensela” or “for Tensela” (an extension, a set of examples), as long as it is
  clear that it is not the official program.

## Please ask first

- Before selling Tensela or including it in something you sell under its name.
- Before using the name or logo in the name of your own product, company, course or domain.

## You cannot

- Distribute a **modified** version of Tensela under the name Tensela or with its logo. The licence lets you change
  the code and share it: do it with a different name and a different logo, and say it is based on Tensela.
- Use the name or the logo in a way that makes people think a product or service is official or endorsed when it
  is not.
