---
title: Exportar
description: Imágenes, dibujos, archivos 3D, impresión 3D, archivos de corte, y llevar el modelo a otro programa.
---

Lo que se exporta es lo que se ve: los nodos con su **ojo** encendido.

| Archivo → Exportar | Para | Teclas |
|---|---|---|
| **Imagen (PNG)** | una imagen de la vista 3D, del tamaño que elijas | Ctrl + Mayús + E |
| **Croquis a mano alzada (PNG, SVG, PDF)** | la vista como un croquis a mano (mira Croquis) | Ctrl + K |
| **DXF (3D o 2D)** | dibujos y modelos para programas CAD | Ctrl + Mayús + D |
| **OBJ** | 3D para cualquier programa: render, BIM, otros modeladores | Ctrl + E |
| **Impresión 3D (STL)**, **Impresión 3D (3MF)** | el laminador de la impresora, en milímetros; revisa antes cada pieza | |
| **Archivo de corte (DXF o SVG)** | el láser o la fresadora: un archivo por plancha, rojo para cortar, azul para grabar | |
| **Blender (.blend)** | una escena de Blender | Ctrl + Mayús + B |
| **IngeTrazo (.igz)** | un modelo de IngeTrazo | Ctrl + Mayús + I |

**Archivo → Abrir en** manda el modelo directo a Blender (Ctrl + B) o a IngeTrazo (Ctrl + I), si están instalados.

**Trucos.**
- Para un archivo de corte, acuesta antes las piezas en planchas con **Acostar en planchas**. Mira
  [Fabricación](/es/manual/nodes/fabrication/).
- El panel **Datos** exporta números: **Guardar como CSV…**.
