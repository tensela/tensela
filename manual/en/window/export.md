---
title: Exporting
description: Images, drawings, 3D files, 3D printing, cutting files, and sending the model to another program.
---

What is exported is what is shown: the nodes with their **eye** on.

| File → Export | For | Keys |
|---|---|---|
| **Image (PNG)** | a picture of the 3D view, at the size you choose | Ctrl + Shift + E |
| **Freehand sketch (PNG, SVG, PDF)** | the view as a hand sketch (see Croquis) | Ctrl + K |
| **DXF (3D or 2D)** | drawings and models for CAD programs | Ctrl + Shift + D |
| **OBJ** | 3D for any program: renderers, BIM, other modellers | Ctrl + E |
| **3D print (STL)**, **3D print (3MF)** | the printer's slicer, in millimetres; it checks each piece first | |
| **Cutting file (DXF or SVG)** | the laser or the router: one file per sheet, red to cut, blue to engrave | |
| **Blender (.blend)** | a Blender scene | Ctrl + Shift + B |
| **IngeTrazo (.igz)** | an IngeTrazo model | Ctrl + Shift + I |

**File → Open in** sends the model straight to Blender (Ctrl + B) or IngeTrazo (Ctrl + I), if they are installed.

**Tips.**
- For a cut file, lay the pieces on sheets first with **Lay flat**. See [Fabrication](/manual/nodes/fabrication/).
- The **Data** panel exports numbers: **Save as CSV…**.
