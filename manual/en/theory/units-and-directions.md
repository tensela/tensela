---
title: Units and directions
description: Metres, degrees, where north is, what time it is, and how numbers are written.
---

| | In Tensela |
|---|---|
| **Lengths** | metres by default: `0.003` is a 3 mm board. You can show them in cm, mm, feet or inches (**Preferences → Units**) and type any unit (`120 cm`, `4'`); the project is always saved in metres |
| **Areas, volumes** | m², m³ |
| **Angles** | degrees: `90` is a right angle; in a Formula, `sin(30)` is 0.5 |
| **Directions** | X goes east, Y goes north, Z goes up |
| **Plan, elevation, side** | *plan* lies on the ground; *elevation* stands facing south; *side elevation* stands facing east |
| **Forces** | newtons: 1 kg weighs about 10 N, 1 kN is 1000 N |
| **Time** | local standard time, without summer time: `13.5` is half past one |
| **Decimals** | a point or a comma: `3.5` or `3,5` |
| **Several values** | separated by a semicolon: `1.5; 2; 3` |
| **A point** | `0 0 0`, `8 0 2.5` or `(0; 0; 1.5)` |

**Exports** use millimetres where the machine expects them: 3D printing files (STL, 3MF) and cutting files (DXF,
SVG) are written in millimetres, and the notice says so.
