# Weather files for the tests

The tests of the Climate node read two typical-year weather files (TMYx, in EnergyPlus format inside a zip), from
[climate.onebuilding.org](https://climate.onebuilding.org). They are not kept in the repository; download them into
this folder to run those tests (without them, the tests are skipped):

- `ESP_MD_Madrid-Barajas-Suarez.AP.082210_TMYx.2004-2018.zip`
- `URY_MO_Montevideo.Prado.865850_TMYx.2011-2025.zip`
